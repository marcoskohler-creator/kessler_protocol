# Security Policy

Kessler executes as the local user and can participate in tool-gating decisions. Treat every hook change as security-sensitive.

Report vulnerabilities privately to the repository maintainer before public disclosure when practical. Do not include real credentials, tokens, private source code, or personal data in public issues.

Kessler is not a sandbox and does not replace operating-system permissions, CI policy, code review, secret scanning, SAST/DAST, or dependency security tooling.
